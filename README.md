# 📊 Risk-Adjusted WACC Educational Page

An interactive, animated educational page explaining **Weighted Average Cost of Capital (WACC)** and **Risk-Adjusted WACC** concepts.

## ✨ Features

- **Smooth Animations**: Page load animations, hover effects, and scroll-triggered animations
- **Interactive Elements**: Clickable code blocks with ripple effects
- **Modern Design**: Clean, professional layout with gradient backgrounds
- **Educational Content**: Comprehensive explanation of WACC concepts with examples
- **Responsive**: Works on all device sizes

## 🚀 Live Demo

Deploy this page to Vercel, Netlify, or any static hosting service.

- `index.html` - Main page with embedded CSS and JavaScript
